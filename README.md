# Eric Muñoz Rouillion — Portfolio

My personal portfolio as a **Computer Engineer** specialised in **Computer Vision** and realistic **3D reconstruction** (Gaussian / Triangle Splatting).

🔗 **Live:** [emr81-ua.github.io](https://emr81-ua.github.io/)

---

## ✨ Highlights

- **Animated hero** — a real-time *gaussian-splat* point cloud rendered on `<canvas>`, coloured by depth (a nod to my thesis on 3D reconstruction).
- **Bilingual** — full 🇪🇸 / 🇬🇧 switch, remembers your choice and detects your browser language.
- **Dark "reconstruction lab" theme**, responsive, and accessible (respects `prefers-reduced-motion`).
- **Projects, about and contact** in one fast, self-contained page.

## 🧰 Built with

- **HTML5 + CSS3** — hand-written, no framework
- **Vanilla JavaScript** — Canvas 2D for the splat animation and the i18n switcher
- **GitHub Pages** — served statically via a `.nojekyll` file (single `index.html`, no build step)

## 📁 Structure

```
index.html      → the whole site (markup, styles and scripts in one file)
.nojekyll       → tells GitHub Pages to serve the HTML as-is
assets/files/   → CV in English and Spanish
favicon.ico
```

> The `_layouts/`, `_sass/` and other Jekyll files are leftovers from the original theme and are no longer used.
